# Oasis Infobyte Internship – Task 3

## House Price Prediction using Linear Regression

### Objective

The objective of this project is to build a Machine Learning model using Linear Regression to predict house prices based on different house features.

### Dataset

The dataset contains information about houses such as:

* Area
* Location
* Number of Rooms
* Year Built
* Quality
* Garage Cars
* Total Basement Area
* Sale Price

### Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

### Steps Performed

1. Loaded and explored the dataset.
2. Checked missing values and duplicate records.
3. Performed data cleaning.
4. Analysed the distribution of house prices.
5. Selected relevant features.
6. Created a correlation heatmap.
7. Handled missing values.
8. Applied One-Hot Encoding to categorical features.
9. Split the data into 80% training and 20% testing sets.
10. Built a Linear Regression model.
11. Predicted house prices.
12. Evaluated the model using MSE, RMSE, and R² Score.
13. Created Actual vs Predicted and Residual plots.
14. Analysed model coefficients.

### Model Evaluation

The model was evaluated using:

* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

### Outcome

The project demonstrates the complete workflow of a house price prediction model, from data preprocessing and feature encoding to model training, prediction, evaluation, and visualization.

### Conclusion

This project helped me understand the practical implementation of Linear Regression for predicting house prices and evaluating machine learning model performance.
